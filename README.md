# No Public Media Manager, a [Dokuwiki Plugin](https://www.dokuwiki.org/plugin:nopublicmediamanager)

By using this plugin you can hide the Media Manager tool (and UI access to media files) to the anonymous public visitors.  
This is uttermost useful when writing your wiki is limited to authorised people.
